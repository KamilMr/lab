# Images

Store publishable diagrams and screenshots by chapter or topic:

```text
images/iam/policy-evaluation-flow.png
images/ec2/security-group-example.png
```

Use lowercase descriptive filenames, relative Markdown links, and meaningful alt text. Before committing an image, check that it contains no AWS account IDs, credentials, email addresses, private URLs, or other personal information.

Prefer your own diagrams. Do not publish copied paid-course slides or large collections of course screenshots.
