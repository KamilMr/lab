# Repository guidance

## AWS SAA-C03 study workspace

The AWS study material lives in `study/aws-saa-c03/`.

- Treat the repository as public. Do not add credentials, account IDs, private URLs, personal data, or screenshots containing them.
- Write original summaries. Do not copy paid course transcripts, slides, quizzes, or other copyrighted material.
- Keep chapter notes in `notes/` and daily reflections in `daily/`.
- Update `progress/current-position.md` when the active course section or lecture changes.
- Mark a sprint day complete only when the daily duty defined in `progress/60-day-sprint.md` is complete.
- Store images under `images/<chapter-slug>/` with descriptive lowercase filenames. Link them with relative paths and add useful alt text.
- Before adding or restructuring Anki cards, load and follow an available Anki-card skill. Keep each card focused on one fact or decision, include enough context to stand alone, and tag it with `aws`, `saa-c03`, and a topic tag.
- Prefer small Markdown files and relative links so notes remain readable on GitHub.
